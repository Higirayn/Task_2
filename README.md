# Task_2 — API-тесты Stellar Burgers

Java 11, Maven, JUnit 5, RestAssured, Allure.

Проверяются создание и вход пользователя, изменение каждого поля с авторизацией и без неё,
создание заказа с разными ингредиентами и получение заказов пользователя.
Классы тестов разделены по ручкам. Пользователи уникальны и удаляются после теста.
Идентификаторы ингредиентов запрашиваются через API. Проверяются код и тело ответа.
Шаги клиентов и подготовки данных отмечены `@Step`.

```shell
mvn clean test
mvn allure:report
mvn allure:serve
```

Результаты: `target/allure-results`. HTML-отчёт: `target/site/allure-maven-plugin/index.html`.
Сохранённые результаты находятся в `reports/allure-results/`, отчёт — в `reports/allure-report/index.html`.
Сохранённый HTML открывается двойным щелчком без сервера.
Фактический прогон: 25 проверок прошли, 4 остановились на ошибках соединения.
Перед сдачей нужен повторный полный прогон при доступном стенде без VPN.

Другой адрес стенда:
```shell
mvn clean test -DbaseUrl=https://qa-stellarburgers.education-services.ru
```

Для невалидного хеша ожидается HTTP 500 и стандартное тело `Internal Server Error`.
Заказ без авторизации с валидными ингредиентами проверяется с ожидаемым HTTP 200.
Тесты требуют доступного учебного стенда; ошибки соединения не подменяются успешными проверками.
